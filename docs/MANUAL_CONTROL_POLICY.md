# ARINA Manual Control Policy

ARINA OS prefers explicit user control over hidden automation.

## User-controllable areas
- Per-app permissions
- Camera / microphone / location access
- Background execution
- Battery optimization
- Auto-start
- Notification delivery
- Mobile data / Wi-Fi access where supported
- Default app roles
- Install unknown apps
- Accessibility services
- Overlay permission
- VPN access
- ARINA Phone / Conference features
- Haptics, transparency and motion
- Developer options

## UX rule
Every manual setting should show:
- current state
- plain-language consequence
- one-tap change where safe
- confirmation for destructive/high-risk changes
- restore-default option

## Guardrails
The OS must not make security-critical protections disappear merely for convenience. Manual control must remain understandable and reversible.

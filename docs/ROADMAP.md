# ARINA OS Roadmap

## Phase 1 — Product system
- Design tokens
- Home / Launcher
- Lock Screen
- Control Center
- Notifications
- Settings shell
- Motion + haptics

## Phase 2 — Communications
- Contacts
- Phone
- Conference Hub
- Hold / mute / speaker
- Multi-call merge
- Telecom integration

## Phase 3 — AOSP product
- Product makefiles
- overlays
- privapp permissions
- SystemUI integration

- bootloader unlock / flashing path
- device tree
- kernel
- vendor blobs
- RIL / IMS / VoLTE / VoWiFi
- audio / display / camera / fingerprint HALs
- SELinux
- AVB / vbmeta

## Phase 5 — Qualification
- boot stability
- battery + thermals
- telephony + emergency calling
- dual SIM
- camera
- fingerprint
- Bluetooth / Wi-Fi
- suspend / resume
- OTA rollback + recovery

# ARINA Home

ARINA Home is the launcher foundation for ARINA OS.

Current foundation:
- AOSP system package
- ARINA design tokens
- premium dark/glass visual baseline
- app-grid and dock composition

Planned implementation:
- installed-app discovery
- original ARINA icon set
- folders and widgets
- wallpaper integration
- drag and drop
- search
- haptics
- spring animations
- gesture integration
- multitasking coordination

Temporary letter tiles are placeholders until final ARINA artwork is added.

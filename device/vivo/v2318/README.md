# Vivo V2318 target

Target device: Vivo V30 5G, model V2318.

This directory intentionally contains no fabricated device tree, kernel config, or proprietary blobs.

A flashable port requires validated:
- bootloader / flashing path
- board + device config
- kernel
- stock vendor blobs
- RIL / IMS / VoLTE
- display / audio / camera / fingerprint HALs
- SELinux
- AVB / vbmeta

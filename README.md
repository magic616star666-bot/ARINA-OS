# ARINA OS

ARINA OS is an AOSP-based operating-system project with original ARINA branding and a premium iOS-inspired interaction model.

## First hardware target
- Vivo V30 5G
- Model: V2318

## Project goals
- ARINA Home / Launcher
- ARINA Lock Screen
- ARINA Control Center
- Notifications
- Settings
- Phone / Conference integration
- System haptics and sounds
- AOSP product overlays
- OTA/update path

## Important
A real flashable V2318 build requires validated device-specific bootloader, device tree, kernel, vendor blobs, RIL/IMS/VoLTE, SELinux and AVB integration. This repository will not invent those pieces.

See docs/ROADMAP.md.
